# نِدائي | تحديثات الساعة

هذا المستودع العام مخصص **للإصدارات المجمّعة للساعة فقط**. مصدر البرنامج محفوظ في مستودع خاص.

## نشر تحديث

1. تأكد من اختبار ملف البرنامج على لوحة ESP32 المطابقة، ومن مطابقة رقم `ClockIdentity::VERSION` للوسم الجديد.
2. افتح [إنشاء إصدار جديد](https://github.com/HMA202/Nidai-Updates/releases/new) واكتب وسمًا مثل `v1.2.0`.
3. أرفق ملفًا واحدًا اسمه بالضبط `firmware.bin`، ثم انشر إصدارًا عاديًا. المسودات والإصدارات التجريبية لا تظهر للتطبيق.
4. يقرأ التطبيق آخر إصدار منشور، ويتحقق من بصمة SHA-256 التي يرفقها GitHub بالملف، ويحفظه لتنصيبه عند الاتصال بشبكة الساعة.

لا ترفع كود المصدر أو كلمات المرور أو ملفات الاستعادة هنا. لا تنشر ملفًا لم يُختبر على الساعة الفعلية.

[الإصدارات المنشورة](https://github.com/HMA202/Nidai-Updates/releases)
